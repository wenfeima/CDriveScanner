========================================
C盘空间扫描器 v1.4
========================================
用途：扫描指定目录（默认 C:\），按占用大小列出子文件夹 / 文件，
      每项标注「这是啥」和「能否删」，勾选后送回收站删除，
      并可直接在资源管理器中定位。
      v1.3 起带体积缓存，往下翻层级不再重复扫描。
      v1.4 起表头列宽自适应，窗口拉窄再拉宽不会把列压扁。

文件说明
--------
C盘空间扫描器_v1.4.exe   主程序（单文件，免安装，双击即用）
cdisk_scanner.py         源码（纯 Python 标准库，可自行修改）
使用说明.txt             本文件
_旧版本/                 历史版本存档（v1.2 / v1.3，可回退）

运行环境
--------
Windows 10 / 11，64 位
无需安装 Python（已打包为 exe）
如需改代码：本机 Python 3.10+ 直接运行 cdisk_scanner.py 即可


--------------------------------
一、基础用法
--------------------------------
1. 双击「C盘空间扫描器_v1.3.exe」打开。
2. 顶部路径框默认 C:\ ，点「扫描」开始。
   （第一次会把所有子目录体积算完并缓存起来，需要等一会儿）
3. 列表按占用从大到小排序，列含义：
   ☑选    = 勾选框
   名称    = 文件/文件夹名
   占用    = 磁盘占用体积
   这是啥  = 用途说明（这栏就是告诉你这东西干什么用的）
   能否删  = 风险等级，绿色=可安全清理 / 橙色=谨慎 / 红色=勿动
   类型    = 文件夹 / 文件
   路径    = 完整路径
4. 底部按钮：
   打开文件夹      在资源管理器中定位选中项
   全选 / 全不选   批量勾选
   删除选中        送入【回收站】


--------------------------------
二、体积缓存（v1.3 新增）
--------------------------------
以前每往下一层都要把整棵子树重新遍历一遍，重复劳动。
现在第一次扫描时会把所有子目录的体积一次性算完并记在内存里，
之后往下翻只做「列目录 + 查表」，几乎不碰磁盘。

实测（C:\\Program Files）：
  冷扫描 1.56 秒  →  进入子目录 0.03 秒      约 25~48 倍加速
  缓存了 4800+ 个目录的体积

顶部按钮：
  扫描        扫描路径框里的目录（优先用缓存）
  ↑ 返回上级  回到父目录（走缓存，瞬时）
  刷新        重新列出当前目录（体积走缓存，瞬时）
  重算此项    清掉当前目录整棵子树的缓存并重新统计（会慢）
  清空缓存    清掉全部缓存，下次扫描重新统计

状态栏右侧会实时显示：缓存目录数 / 命中次数 / 实际统计次数。

缓存规则：
· 纯内存，不写任何临时文件到磁盘。
· 关闭程序时自动清空（WM_DELETE_WINDOW 钩子），不留残留。
· 勾选「重算此项」时，会连带清掉该目录下所有子目录的缓存。
· 若你刚删了一大堆文件、想看最新数字，点「重算此项」。


--------------------------------
三、表头列宽自适应（v1.4 新增）
--------------------------------
以前是 Tk Treeview 自己管列宽：窗口拉窄时它会把后面的列压扁，
但再拉宽时不会自己撑回来，列宽被写死了（路径列只剩一条缝）。

v1.4 改成自己管列宽，规则：
· 固定列（☑选 / 占用 / 能否删 / 类型）保持设定宽度不变
· 弹性列（名称 / 这是啥 / 路径）按默认比例瓜分剩余空间
· 窗口拉窄 → 各列等比收缩；拉宽 → 精确恢复到原来的宽度
· 手动拖过表头分隔线的列会被「锁定」为你拖出来的宽度，
  窗口缩放时不再被改动，其余列自动让出空间
· 底部「重置列宽」按钮可清掉锁定、恢复默认比例

实测（1600 ↔ 800 像素来回拖）：
  宽 1600 → 名称 299 / 说明 429 / 路径 548
  窄  800 → 名称 111 / 说明 160 / 路径 205
  拉回 1600 → 名称 299 / 说明 429 / 路径 548   ← 完全恢复
列宽合计始终 ≤ 表格可用宽度，不会溢出或被挤压。


--------------------------------
四、「这是啥」说明栏
--------------------------------
每个条目都会自动识别用途并给出风险等级，颜色标注：

🟢 可安全清理   删了会自动重建或可重新下载，不影响使用
                 例：NVIDIA 着色器缓存 / 驱动安装包缓存、uv 缓存、
                     pip 缓存、Temp 临时文件、崩溃转储、DirectX 着色器缓存
🟡 谨慎         先点「打开文件夹」看清楚再决定
                 例：软件本体、浏览器数据、Package Cache、模拟器程序目录
🔴 勿动         删了会丢数据或损坏系统
                 例：Windows 系统目录、豆包提示词库、微信/QQ 聊天记录、
                     百度网盘同步数据、Python 解释器、模拟器游戏镜像
⚪ 未识别       规则库里没有的项，自己点「打开文件夹」看一眼

删除时如果勾选项里有红色项，确认弹窗会额外警告。

底部复选框「只看『可安全清理』的项」可以一键过滤出绿色条目，
专门用来找能安全回收空间的垃圾。状态栏也会直接告诉你
当前目录下可安全清理多少项、合计多少体积。


--------------------------------
五、常用操作
--------------------------------
· 勾选：点击第一列的方框（☐ ↔ ☑）切换勾选状态
· 进入子目录：双击文件夹那一行，会下钻继续扫描（走缓存，瞬时）
· 返回上级：点顶部「↑ 返回上级」
· 打开文件夹：选中任意一行点「打开文件夹」
  - 文件 → 资源管理器定位并高亮该文件
  - 文件夹 → 直接打开该文件夹
· 筛选：顶部「仅显示 ≥」下拉可选 全部 / 10MB / 50MB / 100MB / 500MB / 1GB
· 底部右下角实时显示「已选 N 项 / 合计 XX GB」


--------------------------------
六、安全说明（重要）
--------------------------------
1. 删除走 Windows 回收站（SHFileOperation + FOF_ALLOWUNDO），
   不是永久删除，误删可从回收站还原。
2. 删除前有二次确认弹窗，会列出将删除的条目、合计体积，
   并对标红「勿动」的条目额外警告。
3. 建议先「打开文件夹」确认内容再删，尤其是体积大的目录。
4. 无权限的系统目录会显示「无权限」，属正常现象，不影响其他条目。


--------------------------------
七、体积是怎么算的
--------------------------------
1. 跳过目录联接/符号链接（重解析点）。
   Windows 在用户目录下保留了 Application Data、Local Settings、
   My Documents 等兼容性联接，如果跟着它们递归，AppData 会被整份
   重复统计——C:\Users\wenfeima 会从真实的 143GB 虚增到 147GB 以上。
   工具里这类联接显示为「系统兼容性联接（指向别处，勿删）」，体积记 0。
2. 硬链接会重复计入。
   C:\Windows\WinSxS 与 System32 之间存在大量硬链接，两边都算会多算
   约 15GB。这是 Windows 本身的特性，资源管理器同样如此，
   所以「C:\Windows」显示 47.7GB，实际可释放没那么多——它本来就标着勿动。
3. 全盘校验（2026-10-20 实测）：
   各项合计 223.58 GB  vs  磁盘实际已用 208.11 GB，差 15.47 GB，
   即上述 WinSxS 硬链接重复部分，属正常。

--------------------------------
九、重新打包
--------------------------------
在项目目录下执行：
  pyinstaller --onefile --noconsole --name CDiskScanner cdisk_scanner.py
（本机 Python 3.10 自带 PyInstaller 6.22.2，可直接用）
打包后把 exe 改名成 C盘空间扫描器_vX.Y.exe 放回本目录，
旧版挪进 _旧版本/ 即可。

注意：改完 UI 记得先跑一次冒烟测试（真建界面 + 跑一次扫描），
别只做语法检查——v1.1 就是几何管理器冲突导致双击直接崩，
语法检查却完全通过。


--------------------------------
十、扩展说明库
--------------------------------
cdisk_scanner.py 顶部的 KB 列表就是「这是啥」的判断规则，
每行格式：("路径关键字", "说明文字", "风险等级")
风险等级可填：green（可安全清理）/ yellow（谨慎）/ red（勿动）/ gray（未识别）
想让它认识更多软件，直接照着格式往里加行即可。
匹配顺序：KB 路径规则 → 文件名关键字 → 扩展名 → 所在位置兜底。
