# C盘空间扫描器

Windows 桌面小工具：扫描磁盘目录，按占用大小列出子文件夹 / 文件，**每项标注「这是啥」和「能不能删」**，勾选后送回收站删除，并可直接在资源管理器中定位。

纯 Python 标准库实现，打包为单文件 exe，免安装双击即用。

## 功能

| | |
|---|---|
| **体积排序** | 递归统计每个子目录占用，按大小从大到小排列 |
| **「这是啥」说明** | 自动识别每个条目的用途（内置约 110 条规则库） |
| **「能否删」标注** | 🟢 可安全清理 / 🟡 谨慎 / 🔴 勿动 / ⚪ 未识别，四色标注 |
| **勾选删除** | 送入 **Windows 回收站**（可逆，不做永久删除），二次确认 |
| **打开文件夹** | 一键在资源管理器中定位选中项 |
| **体积缓存** | 首次扫描后层级下钻不再重复遍历，实测 25~48 倍加速 |
| **列宽自适应** | 窗口拉窄再拉宽，列宽精确恢复，不被压扁 |
| **阈值筛选** | 只看 ≥ 10MB / 50MB / 100MB / 500MB / 1GB 的条目 |
| **只看可安全清理** | 一键过滤出能安全回收空间的条目 |

## 快速开始

1. 下载 `C盘空间扫描器_v1.4.exe`
2. 双击运行，默认扫描 `C:\`
3. 列表按占用排序，点第一列方框勾选
4. 点「打开文件夹」确认内容 → 点「删除选中（回收站）」

> 删除走 `SHFileOperation` + `FOF_ALLOWUNDO`，进回收站可还原，不会永久删除。

## 界面说明

| 列 | 含义 |
|---|---|
| ☑ 选 | 勾选框 |
| 名称 | 文件 / 文件夹名 |
| 占用 | 磁盘占用体积 |
| **这是啥（用途说明）** | 这东西干什么用的、删了会怎样 |
| **能否删** | 风险等级，按颜色标注 |
| 类型 | 文件夹 / 文件 |
| 路径 | 完整路径 |

底部按钮：`打开文件夹`、`全选`、`全不选`、`删除选中（回收站）`、`重置列宽`，以及「只看『可安全清理』的项」勾选框。

## 常见「可安全清理」项

- NVIDIA 着色器缓存 / 驱动安装包缓存
- `uv` 包缓存、`pip` 安装缓存
- 用户临时文件、程序崩溃转储
- DirectX 着色器缓存

标 🔴 的（Windows 系统目录、豆包提示词库、微信/QQ 聊天记录、百度网盘同步数据、Python 解释器、模拟器游戏镜像）**不要动**。

## 从源码运行

```bash
python cdisk_scanner.py
```

需要 Python 3.10+，**不依赖任何第三方库**（只用 tkinter / ctypes / subprocess / os）。

## 自行打包

```bash
pyinstaller --onefile --noconsole --name CDiskScanner cdisk_scanner.py
```

打完把 exe 改名成 `C盘空间扫描器_vX.Y.exe`，并同步更新 `.gitignore` 里放行的那一行。

## 体积统计口径

工具在统计时会**跳过目录联接 / 符号链接**（Windows 重解析点）。用户目录下保留了
`Application Data`、`Local Settings`、`My Documents` 等兼容性联接，若跟随它们递归，
`AppData` 会被整份重复统计（`C:\Users\<用户>` 会从真实的 143GB 虚增到 147GB 以上）。

另外 `C:\Windows\WinSxS` 与 `System32` 之间存在硬链接，两边都算会多算约 15GB，
这是 Windows 本身的特性，资源管理器同样如此。
